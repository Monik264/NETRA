---

## Problem

Manual analysis of large volumes of crime and intelligence
data makes it difficult to identify hidden relationships,
patterns and connections across cases.

---

## Solution

NETRA(NEetwork exploration and threat relationship analysis) is an AI-powered investigation support system
that analyzes crime data and relationships between entities.

---

## Key Features

- Entity Search
- Criminal Network Visualization
- Case Analysis
- Call Analysis
- Transaction Analysis
- Similar Case Detection
- Hidden Connection Detection
- Crime Timeline
- Network Influence Analysis
- Crime Cluster Detection
- AI Investigation Assistant
- RAG-based Evidence Retrieval
